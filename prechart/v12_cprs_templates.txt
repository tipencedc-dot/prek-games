PRECHART v12: CPRS PERSONAL TEMPLATES
Each block below = one CPRS personal template. Paste the text under COPY BELOW THIS LINE as-is.
Replaces all v11.2 CHIRO templates. Names stay the same, plus one new one (CHIRO EXAM HIP).

HOW TO FILL (memorize once; no prompts inside the templates anymore)
* HISTORY: type terms after the label. Blank = drops from the note.
* EXAM: one test per line, pre-filled "-". Change "-" to "+" and add detail after it.
  Example: Spurling R + neck and arm pain to thumb L -
* A test or side not done: delete it.
* ROM: type over the number. Add ep (end range pain), tr (pain through range), or p.
  Example: Flex 35ep
* IF DONE lines: blank = not done. Type a result only if you did it.
* PLAN is pre-filled with the standard plan. Edit only to change it.
